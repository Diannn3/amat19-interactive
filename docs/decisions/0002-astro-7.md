# ADR 0002 — Implement on Astro 7 rather than the blueprint's Astro 6 baseline

**Status:** Accepted for Pass 1

The V2.0 blueprint was authored against Astro 6. By implementation time, Astro 7.2.6 was the current stable release. Pass 1 therefore pins Astro `7.2.6` while preserving the blueprint's architecture: Content Layer loaders, `@astrojs/react`, static-first pages, and explicit hydration.

This is a version refresh, not a framework rewrite. If a dependency proves incompatible during the first install/build gate, resolve it with the smallest version adjustment rather than changing architecture.
