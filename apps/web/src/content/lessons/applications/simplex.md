## Supplemental status
The current course guide explicitly names linear programming; the older Chapter 4 additionally develops the simplex method. This note is therefore supplemental.

## What a pivot does
A simplex pivot changes the basic feasible solution without changing the represented constraint equations. The lab shows the selected entering column, leaving row, pivot value, and resulting tableau for supported standard maximization models.
